## **Banking Data Visualization and Analysis using Power BI**

### Project Overview

This project uses Microsoft Power BI to analyze banking data across deposits, loan portfolios, and branch performance. It presents key metrics and trends through interactive visualizations and slicers.

Tools Used

- Microsoft Power BI Desktop
- Power Query
- DAX
- Data Visualization

Report Pages

1. Deposits vs Targets

- Total Deposits
- Total Deposit Target
- Deposit Achievement Percentage
- Deposit by Product Type
- Monthly Deposit Trend
- Monthly Deposits vs Target
- Deposit Distribution by Branch
- Filters: Product Code, Branch ID, Month, and Year

2. Loan Portfolio

- Total Outstanding Balance
- Total EMI Amount
- Loan Portfolio by Product
- Monthly EMI Amount Trend
- Monthly EMI Collection
- Filters: Loan Product, Year, and Branch Name

3. Branch Performance

- Total Deposit
- Total Deposit Target
- Deposit Achievement
- Monthly Deposit Trend
- Deposit Achievement by Region
- Deposit Target by Branch
- Region and City filters

Dataset Tables

- DimDate
- DimProduct
- DimBranch
- DimAccount
- DimMonth
- FactTransactions
- FactLoanRepayments
- BranchDepositTargets

Key Features

- Three interactive report pages
- KPI cards for key banking metrics
- Monthly trend analysis
- Product-wise loan analysis
- Deposit target comparison
- Branch and regional performance analysis
- Interactive slicers and page navigation

How to View the Project

1. Clone or download this repository.
2. Open the ".pbix" file in Power BI Desktop.
3. Navigate through the three report pages.
4. Use the slicers to explore the available data.

Project Objective

To demonstrate the use of Power BI for transforming banking data into meaningful visual insights through data modelling, analysis, and interactive reporting.
